# BudgetTracker – Setup und Updates

Hier liegen die Installationsdateien von **BudgetTracker**, dem Finanzbegleiter von
[CS Logics](https://www.cslogics.de). Der Quelltext ist nicht öffentlich.

- **Herunterladen:** unter [Releases](https://github.com/csidi90/budgettracker-releases/releases) die neueste
  `BudgetTracker-Setup-….exe` (Windows). Infos und Preise: [www.cslogics.de](https://www.cslogics.de).
- **Updates:** BudgetTracker lädt neue Versionen selbst von hier und prüft jede mit Prüfsumme und Signatur, bevor es
  sie installiert.
